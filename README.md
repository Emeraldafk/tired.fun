# Tired.fun — Degen Mansion Knock Knock 🎃

An exact replica of the POV Degen Mansion countdown and knock experience modeled for **Tired.fun**, incorporating the official **Tired.fun** banner and comic art.

## ✨ Features

- **Iconic Visuals**:
  - Purple stone brick wall background with gothic lighting
  - Carved double mansion doors with animated brass ring knockers
  - Semicircular 13-pane fanlight transom arch with radial glowing gradients
  - Glowing Jack-o'-lantern pumpkins with flickering eyes
  - Warm carriage wall lanterns on either side
  - Drifting atmospheric creeping fog layers
- **Interactive Knocking Mechanics**:
  - Clicking the door knockers plays the official `/sound/knock.wav` sound effect
  - Realistic swinging knocker ring animation and door rattle
  - Each knock progressively lights up a pane in the 13-pane fanlight arch
  - Eruption of flying Halloween treats/candies (`🍬`, `🍭`, `✨`, `🎃`) on every knock
- **Soundtrack & Ambient Audio**:
  - Sound toggle button in the header for looping the eerie `/sound/music.mp3` background score
- **Countdown Tag**:
  - Hanging tag badge from the spiderweb arch showing `Opens in 4 days`
  - Clickable to toggle between days and a live ticking countdown clock
- **Brand & Content Integration**:
  - Brand header lockup with Tired.fun typography and pumpkin mascot
  - Hero copy: `Knock knock.` and `Trade on Tired.fun for knocks and candies.`
  - CTA button: `Sign in with Tired.fun`
  - Offer cards:
    - **Spooky Ranks**: `$7,000` pool for the top 50
    - **Knocks**: `Upto $500` behind any knock
  - Social & Community links:
    - X (Twitter): [@TheTiredFun](https://x.com/TheTiredFun)
    - Website: [Tired.fun](https://tired.fun)
    - Rules & Info modal
  - **Banner Art Showcase**: Dedicated modal viewing the full Tired.fun banner and comic panels

## 🚀 Running the Project

```bash
# Start the local server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) in your web browser.
